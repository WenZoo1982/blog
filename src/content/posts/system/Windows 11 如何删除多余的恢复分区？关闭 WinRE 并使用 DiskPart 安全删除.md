# Windows 11 如何删除多余的恢复分区？关闭 WinRE 并使用 DiskPart 安全删除

在使用 Windows 11 的过程中，有些电脑可能会出现多个恢复分区，每个分区通常占用几百 MB 到 1GB 左右的磁盘空间。

这些恢复分区通常用于存放 Windows 恢复环境（WinRE），为系统提供高级启动、自动修复、重置此电脑等恢复功能。

如果你习惯在系统出现严重故障时，直接使用 Windows 安装 U 盘重新安装系统，并不打算使用 Windows 自带的恢复功能，那么可以考虑删除不再需要的恢复分区，释放磁盘空间。

本文介绍如何关闭 Windows RE，并使用 Windows 自带的 DiskPart 工具删除恢复分区。

## 一、为什么磁盘中会出现多个恢复分区？

Windows 恢复分区主要用于存放 Windows 恢复环境及相关恢复文件。

电脑出现多个恢复分区，常见原因包括：

1. **Windows 版本升级：** Windows 在功能更新过程中，可能因为原有恢复分区空间不足而创建新的恢复分区。
2. **多次重装系统：** 不同安装方式可能留下之前的恢复分区。
3. **OEM 厂商预装：** 部分品牌电脑会创建厂商专用恢复分区。
4. **磁盘分区调整：** 使用分区工具调整磁盘布局时，可能保留原来的恢复分区。

需要注意，并不是所有标记为恢复分区的分区都可以直接删除。特别是品牌电脑的 OEM 恢复分区，可能包含厂商提供的出厂恢复文件。

## 二、删除恢复分区之前需要了解什么？

删除 Windows 恢复分区后，以下功能可能受到影响：

- Windows 高级启动中的恢复环境
- Windows 自动修复
- 部分系统故障恢复功能
- 重置此电脑

如果你不需要这些功能，并且已经准备好 Windows 安装 U 盘，可以考虑删除。

删除前请确认：

- 已备份重要数据。
- 已准备好 Windows 安装 U 盘。
- 已确认目标分区不是 EFI 系统分区。
- 已确认目标分区不是 MSR 分区。
- 已确认目标分区不是 OEM 厂商专用恢复分区。

## 三、第一步：关闭 Windows RE 恢复环境

Windows 自带一个管理恢复环境的命令行工具：`reagentc`。

首先，以管理员身份打开 Windows PowerShell。

可以右键点击开始菜单，选择「终端（管理员）」或「Windows PowerShell（管理员）」。

输入以下命令：

```
reagentc /disable
```

执行后，Windows RE 将被禁用。

接下来输入：

```
reagentc /info
```

查看当前恢复环境状态。

如果显示：

```
Windows RE status: Disabled
```

说明 Windows RE 已成功禁用。

注意：关闭 Windows RE 与删除恢复分区是两件不同的事情。禁用后仍需要单独删除不再需要的分区。

## 四、第二步：使用 DiskPart 查看磁盘分区

Windows 自带 DiskPart 磁盘分区管理工具，可以通过命令行管理磁盘和分区。

在管理员 PowerShell 中输入：

```
diskpart
```

进入 DiskPart 后，首先查看电脑中的磁盘：

```
list disk
```

例如：

```
磁盘 ###  状态       大小
磁盘 0    联机       476 GB
磁盘 1    联机       931 GB
```

假设 Windows 系统安装在磁盘 0，输入：

```
select disk 0
```

接下来查看该磁盘中的分区：

```
list partition
```

例如：

```
分区 ###  类型       大小
分区 1    系统       100 MB
分区 2    MSR        16 MB
分区 3    主要       475 GB
分区 4    恢复       900 MB
```

这里可以看到，分区 4 的类型为恢复，大小为 900MB。

注意：以上只是示例，实际分区编号和容量以自己的电脑为准。

## 五、第三步：确认恢复分区信息

确定准备删除的分区编号后，输入：

```
select partition 4
```

这里的数字 4 需要替换成实际恢复分区编号。

接着输入：

```
detail partition
```

查看当前分区的详细信息。

重点检查分区类型、容量以及相关属性，确保它确实是准备删除的 Windows 恢复分区。

如果无法确定分区用途，不要继续操作。

特别注意：EFI 系统分区负责引导 Windows 启动，MSR 是 GPT 磁盘上的 Microsoft 保留分区，两者都不能误删。

## 六、第四步：强制删除恢复分区

确认目标分区无误后，执行：

```
delete partition override
```

DiskPart 会尝试强制删除当前选中的分区。

如果提示成功删除所选分区，说明删除操作已经完成。

最后输入：

```
exit
```

退出 DiskPart。

## 七、第五步：检查分区删除结果

按下 `Win + X`，打开「磁盘管理」。

找到刚才操作的磁盘，检查原来的恢复分区是否已经变成「未分配」空间。

如果显示为未分配，说明恢复分区已经删除。

需要注意：删除分区后，释放出来的空间不一定能够直接扩展 C 盘。

只有当未分配空间紧邻 C 盘右侧时，Windows 磁盘管理通常才能直接扩展 C 盘。如果中间还有其他分区，则需要另外规划分区布局。

## 八、总结

对于不需要 Windows 自带恢复功能、习惯使用安装 U 盘重新安装系统的用户，可以考虑关闭 Windows RE 并删除不再需要的恢复分区。

整个操作主要分为三个环节：

1. 使用 `reagentc /disable` 关闭 Windows RE。
2. 使用 DiskPart 查看并确认目标恢复分区。
3. 使用 `delete partition override` 删除确认无误的分区。

需要强调的是，删除恢复分区并不会卸载 Windows，也不会影响正常的日常使用，但会失去依赖该恢复环境的部分系统修复功能。

**最后提醒：** 不要仅凭分区容量判断其用途。操作前务必确认分区类型和实际用途，尤其不要误删 EFI、MSR 或 OEM 厂商恢复分区。
